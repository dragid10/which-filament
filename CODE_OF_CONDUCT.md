# Code of Conduct

We want this project to be welcoming to everyone, whatever their experience with 3D printing.

**Expected behaviour**
- Be kind and respectful; assume good intent.
- Give and accept constructive feedback gracefully.
- Keep discussion focused on making the guide better.

**Unacceptable behaviour**
- Harassment, insults, or discriminatory language.
- Personal attacks or trolling.
- Publishing others' private information.
- Spam or undisclosed promotion.

Maintainers may edit or remove contributions that violate this code and may block repeat offenders. To report a problem,
open a private security advisory on the repository or contact the maintainer through their GitHub profile.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
